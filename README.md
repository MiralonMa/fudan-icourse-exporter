# 复旦 icourse 课程资料提取与 PPT 精简工具

**本项目仅适用于复旦大学 icourse 网站（[icourse.fudan.edu.cn](https://icourse.fudan.edu.cn)），不适用于其他学校或其他录播平台。**

启动后选择“仅字幕”“仅 PPT”或“两者都提取”，输入录播网址，在独立浏览器窗口中自行登录一次，即可导出字幕 TXT、清晰 PPT 原图及 PDF。不提取音频或视频，不自动纠正语音识别文字。

统一入口为 `extract_course.py`，Windows 用户可直接双击 `启动课程提取.cmd`。支持 PPT 断点续传、缺页检查、全程默认页面筛选（包含课间），以及部分任务失败后只重试未完成内容。仓库名称为 `fudan-icourse-exporter`，同时涵盖字幕和 PPT 的导出与整理。

## 环境要求

- Windows，Python 3.10 或更高版本，本机已安装 Edge 或 Chrome。
- 默认页面自动识别使用 Windows 自带的本机 OCR（通常需已安装中文文字识别）；不下载语言包，不调用在线 OCR。若不可用，工具会提示并保留未确认页面，字幕和原图仍可提取。
- 能够通过校园网或校园 VPN 访问目标录播，并拥有该课程的正常访问权限。
- 只使用 Python 标准库，无需 `pip install`，无需下载驱动或浏览器，也不依赖在线转换服务。

校园网仍用于正常登录和加载课程。工具通过本机临时调试端口读取浏览器页面，并使用同一登录会话请求 PPT 原图。

## 使用方法

1. 下载或克隆源码并解压到可写目录。
2. 双击 **`启动课程提取.cmd`**，或运行 `python extract_course.py`。
3. 输入 `1` 仅提取字幕、`2` 仅提取 PPT、`3` 两者都提取；输入 `q` 退出。
4. 输入你自己的 icourse 录播页面完整网址。
5. 在工具新开的独立浏览器窗口中手动登录，返回目标录播页。
6. 若选择 PPT，先点击右侧小窗口的切换图标，打开清晰 PPT 并确认后面的图片能加载。
7. 若选择字幕，再打开“语音识别”，清空搜索框，等待字幕完整加载。
8. 回到工具窗口按回车，导出所选内容。

默认结果保存在脚本旁的 `提取结果/课程标题_课程标识/`：同一节录播的字幕 TXT（及可选 JSON）、PPT PDF、`PPT清单.json` 和 `images/` 原图缓存放在同一个课程文件夹中。课程标识由清理后的录播网址生成，不同节次会分开；分两次选择“仅字幕”和“仅 PPT”也会使用同一课程目录。三个 Windows 启动文件都使用这一布局。一次运行只打开一个独立浏览器，共用一次手动登录。

```text
提取结果/
  课程标题_课程标识/
    课程标题_中文字幕.txt
    课程标题_PPT_精简N张_原M张.pdf
    PPT清单.json
    images/
```

已有的旧版 `字幕/`、`PPT/` 目录不会自动移动或删除；旧 PPT 下载目录仍可用 `--filter-existing` 离线筛选。

两项都选时，若其中一项失败，另一项的成功结果会保留。修正网络或页面加载状态后再次按回车，只重试未完成部分，已经成功的字幕不会重复生成。请保持同一课程页面；导出一项成功后若切换到其他课程，工具会提示回到原课程，避免混合课程资料。

退出时会关闭本次工具打开的独立浏览器；平时使用的浏览器窗口不受影响。两个单项启动文件也已接入统一入口；直接运行旧的 `extract_subtitles.py`／`extract_ppt.py` 仍保留兼容用法与旧输出布局，推荐使用统一入口或启动文件。

## 清晰 PPT 导出

1. 双击 `启动课程提取.cmd`，选择 `2` 或 `3`，输入录播网址。
2. 在新开的独立浏览器窗口中手动登录，并返回录播页。
3. 点击页面右侧小窗口左上角的切换图标，显示 PPT；可再将 PPT 切换为大窗口。
4. 尝试切到后面的页，确认新内容可以加载；如果仅首张可见，通常尚不能完成下载。
5. 回到工具窗口按回车。工具读取完整列表，通过同一登录浏览器下载原图，再生成 PDF。

统一入口的 PPT 输出与字幕一起位于 `提取结果/课程标题_课程标识/`，包含原图 `images/`、续传与缺页清单 `PPT清单.json` 以及完成后的 PDF。缓存会同时核对课程来源、图片清单和图片哈希；同一目录若出现不同图片清单，会要求另选输出目录，避免混用原图。

页面左侧列表的 `s_时间戳.jpg` 是缩略图；在已观察到的 PPT 查看器资源中，对应原图为同目录下的 `时间戳.jpg`。工具要求页面至少出现一个匹配的查看器原图资源后才使用这个规则。如果网页结构变化，会报告错误，不会静默改用低清缩略图。

原图通过页面内同源 `fetch` 和浏览器已有登录会话读取，不导出 Cookie，不另行获取学校密码。图片需通过浏览器解码、JPEG 结构与宽高校验；默认最小尺寸为 800×450，失败会重试。PDF 直接嵌入 JPEG 原始字节，不重新压缩、不放大图片像素；每页标注原序号和时间戳，并提供书签。

**默认必须全部图片成功后才生成完整 PDF。** 遇到 3 张读取失败时会停止并保留已下载图片。恢复校园网后，以相同输出目录重新登录运行即可续传；缓存会校验 SHA-256。退出、取消或重试不会删除已下载的原图。

若明确需要缺页版本，可在命令行添加 `--allow-partial`；文件名会标明“部分 X 张／共 Y 张”，清单列出所有缺页。原图始终按网站原列表缓存；PDF 默认筛除整条时间轴中已确认的录播默认页面，包含课前、课间和课后。普通课件的重复页仍保留。

### 筛选全程默认页面（含课间）

**正常提取会先筛选页面，再直接生成筛选后的 PDF，不会先输出一份未筛选 PDF。** 默认开启自动筛选；如果没有足够证据筛除页面，PDF 会保留全部原页。`--ppt-filter off` 可关闭自动筛选。原图缓存用于续传和恢复，仍按原始清单完整保存。

默认 `--ppt-filter auto`：先在本机将原图按视觉相似度分组，再用 Windows 自带 OCR 核对每组代表图。只有同时包含录制操作、视频获取／教室分布等说明和复旦录播指南／平台标记的画面，才成为默认页面模板；随后匹配整段课程的所有原页，不要求头尾相同，不限制默认页面占比。默认页中变化的横幅、时钟等小区域可容许一定差异。

识别在本机完成，不上传图片，OCR 文本只用于内存中的判断，不保存到报告。不因“无字幕”“截图密集”或“重复次数多”删除普通课件、课程封面和浏览器中的教学内容。OCR 不可用、默认界面大幅变化或画面不能确认时会保留并在报告注明；因此不承诺识别任意样式的浏览器主页。请核对清单中的原序号、模板序号和匹配距离；原图不删除，可用 `--ppt-filter off` 恢复全部页面。若全部页面都被确认是默认页，会提示没有课程页面，不生成空 PDF。原 PDF 不会被离线筛选覆盖，已下载缓存仍用于续传。

字幕首尾可能包含课前交流或课后答疑，不能直接当作讲课起止。程序只读取字幕时间和字数作为核对证据，在筛选清单逐页记录显示区间、字幕条数和字数；不会因为页面仍有字幕就把重复主页保留，也不会因为没有字幕就删除真实课件。

若已核对课程的确切起止，可加 `--start-time HH:MM:SS --end-time HH:MM:SS`。程序按页面实际显示区间判断重叠，保留开始时间之前出现、但在开始时间仍显示的那一页。

```powershell
python extract_course.py --extract both
python extract_course.py --extract ppt --ppt-filter off
```

### 已下载课程无需重下

指定包含 `PPT清单.json` 和 `images/` 的课程下载目录，即可在本机重建 PDF，无需登录或重新下载：

```powershell
python extract_course.py --filter-existing ".\提取结果\课程标题_课程标识"
python extract_course.py --filter-existing ".\课程下载目录" --subtitles-file ".\课程字幕.txt"
python extract_course.py --filter-existing ".\课程下载目录" --start-time "00:05:00" --end-time "01:40:00"
```

以上目录、文件名与时间为示例，需换成自己的课程数据。`--subtitles-file` 可选，支持本工具导出的 TXT 或 JSON；`--filtered-output` 可指定另存 PDF 的位置。该流程会先校验原图哈希，使用临时无头 Edge／Chrome 解析本机图片，不向课程网站发出图片下载请求。仍只需 Python 标准库及现有浏览器。

另存的 PDF 旁会生成 `.筛选报告.json`，包含保留／筛除序号、逐页依据和字幕时间证据。正常提取时，相同信息记录在 `PPT清单.json` 的 `filter` 字段。筛选只减少 PDF 中的页面，不自动清理原图缓存或旧 PDF；核对后可自行清理旧文件。

```powershell
python extract_course.py --extract ppt --url "https://icourse.fudan.edu.cn/livingroom?course_id=0&sub_id=0&tenant_code=0"
python extract_course.py --extract both --allow-partial
```

示例数字 0 是占位符。其他参数包括 `--output-dir`、`--browser`、`--retries`、`--min-width`、`--min-height`，使用 `--help` 查看。降低最小宽高仅适合确认过实际原图尺寸的课程；它不会改善低分辨率图片。

目前支持同源的 8 位灰度／RGB JPEG 原图。PPT 规则针对复旦 icourse 适配，代码没有网址域名白名单；其他站点不保证可用。PDF 生成也只使用 Python 标准库，无需额外安装 PDF 库。

命令行也可指定网址及输出位置。下面的数字 **0 均为占位符**，需替换为你自己课程地址中的值：

```powershell
python extract_course.py --extract both --url "https://icourse.fudan.edu.cn/livingroom?course_id=0&sub_id=0&tenant_code=0" --output-dir ".\提取结果"
python extract_course.py --extract subtitles
```

网址包含 `&`，在命令行中必须加引号。不要把登录账号、密码或验证信息写入命令。

可选参数：

| 参数 | 作用 |
| --- | --- |
| `--url` | 录播网址，省略则交互输入 |
| `--extract` | `subtitles` 仅字幕、`ppt` 仅 PPT、`both` 两者；省略则显示菜单 |
| `--output-dir` | 指定本机保存根目录，其下每节录播一个文件夹，同课字幕和 PPT 放在一起 |
| `--browser` | 指定 Edge／Chrome 可执行文件路径 |
| `--json` | 额外保存结构化字幕清单 |
| `--ppt-filter` | `auto` 本机识别并筛除全程录播默认页面（含课间），`off` 关闭自动筛选 |
| `--start-time` / `--end-time` | 可选的 PPT 手动时间窗；独立于自动筛选开关 |
| `--filter-existing` | 从已有下载目录离线重建 PDF，跳过登录和选择菜单 |
| `--subtitles-file` | 离线筛选时可选的字幕 TXT／JSON |
| `--filtered-output` | 离线筛选 PDF 的另存路径 |
| `--help` | 查看帮助 |

TXT 使用 UTF-8（含 BOM），保留原文、重复语句、英文片段和识别错误。例如，以下为合成示例：

```text
[00:00:01] 这是用于说明格式的示例字幕。
```

已有同名文件会追加编号，不会覆盖旧 TXT。

## 完整性与适用边界

程序读取当前 DOM 中 `.trans-item` 内的 `.item-origin > span`，以之前的 `.item-time` 作为时间戳。它会核对 DOM 数量、文字非空、时间戳格式及顺序，并在保存后回读验证。

这些检查不能证明网站尚未加载的数据也已导出。请自行核对末条时间是否覆盖所需课程，并确认没有搜索筛选。网站若改用分页、虚拟列表或修改类名，需要相应更新提取流程。

支持主页面及同源内嵌框架；跨域内嵌字幕尚未适配。代码不限制网址域名，但本项目仅针对复旦 icourse 的页面结构适配，其他站点不保证可用。统一身份认证可能跳转至登录站点，请自行完成登录并回到 icourse 后再提取。

## 隐私与本地数据

- 不内置任何用户账号、密码、Cookie、令牌、实际课程地址或字幕样本。
- 不读取日常浏览器配置，不调用账号或密码读取接口，不上传字幕或图片，不设置数据收集或遥测服务。
- 手动登录时，浏览器会按学校正常流程向学校认证服务提交信息。独立会话的登录资料暂存在本机临时浏览器目录，正常退出时尝试清理；强制结束或文件占用可能导致残留。
- 保存的来源地址仅保留数字形式的 `course_id`、`sub_id`、`tenant_code` 参数，丢弃其他查询参数和 URL 片段，避免复制登录令牌。
- 运行生成的 TXT／JSON／图片／PDF 可能包含课程或个人信息，供用户本地保存；不要将它们或浏览器临时目录上传到仓库。`.gitignore` 已排除常见输出、缓存、截图和凭据文件。
- 使用本项目仅导出你有权访问的内容，并遵守课程资料的使用要求。

仓库仅包含工具代码、说明和合成测试数据，不包含开发时的真实课程资料、截图、浏览器记录或本机路径。浏览器自身的联网行为由浏览器及学校登录流程决定。

## 验证

```powershell
python -m unittest discover -s tests -v
```

标准测试完全离线，使用合成数据检查保存、文件名、异常数据拦截、网址格式和来源地址清理。

如本机已安装 Edge／Chrome，可额外运行浏览器集成测试：

```powershell
$env:RUN_BROWSER_TESTS="1"
python -m unittest discover -s tests -v
```

集成测试在临时目录生成 2,903 条合成字幕，使用独立无头浏览器逐条比对。它不访问校园网，不代表已验证登录后的在线整流程。

PPT 测试使用合成 JPEG 与本机 HTTP 页面，验证原图获取、字节完整性、PDF 结构、断点续传和缺页处理。统一入口还测试三种选择、共用一个浏览器、失败后仅重试剩余内容，以及一次运行同时生成字幕和 PDF。筛选测试覆盖本机文字识别的多重证据、课间默认页删除、默认页占绝大多数、普通重复课件保留、OCR 不可用时保留、时间窗重叠、字幕证据、同课共用目录及已有文件不覆盖。测试不代替校园网登录后的实际使用验证。

## 常见问题

- **未发现字幕**：检查独立窗口已登录并回到 icourse 录播页，打开“语音识别”，清空搜索并等待加载。
- **校园网无法访问**：先恢复校园网或校园 VPN；本工具不绕过学校认证。
- **启动超时**：确认浏览器路径正确；设备策略可能禁止浏览器调试端口。
- **找不到 Python**：使用已有 Python／Anaconda 环境中的 Python 3.10+ 运行。
